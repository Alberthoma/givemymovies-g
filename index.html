Ajustes

Sin clave, la app funciona en modo demo con un catálogo de ejemplo. Con clave accedes a más de 90 países y cientos de plataformas, con datos reales. Es gratis:

  1. Crea una cuenta en themoviedb.org.
  2. Entra en Ajustes → API y solicita una clave de uso personal.
  3. Copia la API Key (v3 auth) y pégala arriba.

La clave se guarda solo en este navegador. Si algún día publicas la web, ten en cuenta que sería visible en el código; para eso haría falta un pequeño servidor intermedio.

Opcional. Sin ella la app funciona igual; solo que las fichas no muestran las notas de IMDb, Rotten Tomatoes ni Metacritic. Es gratis (1.000 consultas al día):

  1. Pídela en omdbapi.com/apikey.aspx (plan FREE!).
  2. Activa la clave desde el enlace que llega a tu correo.
  3. Pégala arriba.

Opcional. Conecta tu Google Drive para que la app busque sola tus copias por título y las reproduzca dentro. Solo funciona en la web publicada (HTTPS), no con doble clic, y pide permiso de solo lectura. Sin esto sigues pudiendo pegar el enlace a mano (Nivel 1). Gratis:

  1. En console.cloud.google.com crea un proyecto y activa la Google Drive API.
  2. Crea un ID de cliente de OAuth tipo Aplicación web y añade el origen https://alberthoma.github.io.
  3. Pega aquí el Client ID y pulsa Conectar con Drive.

Tus datos se guardan solo en este navegador. En este PC usa http://127.0.0.1:7399. Para entrar desde fuera de casa usaremos una URL HTTPS privada de Tailscale, sin abrir puertos del router.
